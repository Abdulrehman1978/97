## 8. Root Cause Analysis

1. **Error Code**: `0x800705aa` (`ERROR_NO_SYSTEM_RESOURCES` - "Insufficient system resources exist to complete the requested service").
2. **Mechanism**:
   - The host has ~2.69 GB free physical RAM remaining out of 15.38 GB.
   - Without a `.wslconfig` file, WSL2 defaults to requesting 50% of host RAM (~7.7 GB) for the VM creation request sent to Hyper-V Host Compute Service (`vmcompute`).
   - `vmcompute` cannot commit an unbounded ~8GB VM instance while physical RAM is constrained.
   - Failed initialization left stale `com.docker.backend` (PID 28732, 819 MB), multiple Docker Desktop UI helper processes, and orphaned `vmmem` (PID 15740, 835 MB) holding system resources.
   - These orphaned processes prevented clean restart of the WSL utility VM.
