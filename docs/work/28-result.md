## 1. Architecture: What Changed & Why

1. **Modular Typed Frontend API Layer**: Created `apps/web/src/lib/api/` (client, auth, beneficiary, intelligence, opportunities, journey, admin, integrations, offlineQueue, errors) to eliminate runtime import breaks and provide typed request/response contracts, authorization headers, timeout abort controllers, and offline mutation queues.
2. **FastAPI Authorization Layer**: Replaced uninvoked standing policy utilities with `get_current_user`, `get_current_user_optional`, and `require_roles()` FastAPI dependencies. Beneficiaries cannot access administrative intelligence or audit logs.
3. **Bcrypt Password Security**: Replaced plaintext/mock login with industry-standard `bcrypt` hashing (work factor 12) with salt generation. Login returns HTTP 401 on bad password and HTTP 403 on disabled accounts, eliminating arbitrary auto-creation.
4. **Relational Database & Migrations**: Configured PostgreSQL with `psycopg[binary]`, initialized Alembic with an autogenerated baseline migration (`alembic/versions/2ef374a0880a_initial_schema_v3.py`), and enforced SQLite WAL mode with `busy_timeout=30000` to prevent database locking during concurrent operations.
5. **Truth-State Governance Engine**: Relabeled synthetic fixtures (`Ramesh Mesram`, `Nagpur PM-AJAY-NAG-2026-B1`, synthetic vacancies, district demand) to `DEMO_DATA`; relabeled telephony and WhatsApp sandbox adapters to `SANDBOX`; and marked external government integrations to `ADAPTER_READY`.

## 2. Critical Fixes Summary

- **Removed Fake Success Fallbacks**: `/help` no longer catches API exceptions and pretends the grievance was submitted. It displays real persisted ticket IDs (`GRV-2026-NAG-...`), queues offline mutations with `client_mutation_id` when disconnected, and distinguishes `SANDBOX` from `LIVE` callback requests.
- **Candidate Anti-Discrimination Protection**: Redacted caste, subcaste, religion, income, and BPL card numbers from employer views. Beneficiary first names are strictly pseudonymized to a single initial (e.g. `"R."`).
- **Interactive Counterfactual Recalculation**: Live travel radius buttons (5km, 15km, 25km), work type toggles (wage, self-employment, hybrid), and wheelchair accessibility toggles trigger real-time backend recalculation.
- **Multi-Session Beneficiary Journey**: Action checklist toggle actions call `PUT /api/v1/journey/actions/{id}` and persist completion state across browser reloads.
- **Production Containerization**: Created multi-stage `backend/Dockerfile` and `apps/web/Dockerfile` verified with `docker compose config`.
