## 6. Authentication

- **Algorithm**: Cryptographic one-way **bcrypt** hashing with salt generation (work factor 12).
- **Tokens**: Signed HMAC-SHA256 JWT access tokens with subject and expiration claims.
- **Database Authority**: Token role claim is verified against active database record on every protected request. Disabled or deleted users are rejected immediately.
- **Failures**: Invalid credentials return HTTP 401; disabled accounts return HTTP 403; expired or tampered tokens return HTTP 401.
